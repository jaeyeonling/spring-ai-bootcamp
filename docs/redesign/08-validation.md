### 1차 결과 해석

**hard (30.8%) ✓**: 벽이 충분히 작동. `cross_language`, `precedent`, `memory` 타입이 어려움을 만들어냄.

**medium (61.4%) ✗**: 벽이 너무 약함. 원인:
1. `conditional` 질문(43개 중 ~20개 medium)이 LLM에게 너무 쉬움
2. agent_jung이 top-k에 있어도 LLM이 current 정책 문서를 우선 신뢰
3. `versioning` 질문이 6개뿐으로 샘플 부족

**easy (60.0%) ✗**: agent_jung 오염율 50%가 영향. 쉬운 질문에도 오답 로그가 절반 포함됨.

## 2차 개선 계획

### 개선 방향: medium 질문 강화

`medium` 목표: 25-40% (현재 61.4% → 목표 35% 이하)

필요한 변화: 현재 27개 정답 → 목표 ~16개 정답 (11개를 오답으로 전환)

| 전략 | 설명 |
|------|------|
| versioning 질문 추가 | deprecated 포인트 적립률/반품 기간이 혼재된 질문 추가 |
| noise 질문 강화 | agent_jung 오답이 확실히 영향 주는 시나리오 |
| conditional → versioning 교체 | 단순 조건 분기를 버전 충돌 조건으로 교체 |

### 추가할 medium 질문 유형

1. **versioning**: "Standard 회원 포인트 적립률이 얼마나 되나요?" — deprecated(3%) vs current(1%) 충돌
2. **versioning**: "Plus 등급이 되려면 연간 얼마를 써야 하나요?" — deprecated(150만) vs current(200만) 충돌
3. **noise**: "반품 신청을 했는데 기간이 7일이라고 상담사가 말했어요" — agent_jung 오답 직접 언급
4. **versioning**: "무료배송 기준이 바뀐 게 맞나요?" — 30,000원 → 20,000원 변경 이력
5. **contradiction**: 여러 버전의 반품 기간을 혼재시킨 질문

## 2차 결과 (2026-04-05, Q101~Q115 추가 후)

versioning 8개 + noise 7개 = 15개 질문 추가 (총 115개).

| Tier | 정답 | 전체 | 정확도 | 목표 | 판정 |
|------|------|------|--------|------|------|
| easy | 18 | 30 | **60.0%** | 70%+ | ✗ |
| medium | 40 | 59 | **67.8%** | 25-40% | ✗ (오히려 상승) |
| hard | 7 | 26 | **26.9%** | ≤35% | ✓ |

### 2차 실패 원인 분석

**① "X라고 들었는데 맞나요?" 형태가 역효과**
- 의심을 신호하는 질문 → LLM이 사실 검증 모드로 동작 → 정답 추출 성공
- noise wall_type 정확도: 75% → **81.8%** (오히려 상승)

**② RAG의 벽은 검색 단계에서 생긴다 (생성 단계가 아님)**
- 작동한 벽: cross_language(33%), memory(0%), precedent(0%) → **검색 자체 실패**
- 실패한 벽: versioning(57%), noise(82%) → 모순 컨텍스트에서도 LLM이 정답 추출

**③ GPT-4o-mini는 모순된 컨텍스트에서 reasoning 강함**
- deprecated + current 문서가 동시에 검색돼도 current 정책을 올바르게 선택
- 데이터 모순으로 LLM reasoning을 실패시키기는 어려움

## 3차 개선 계획 (비격식체 + 멀티홉)

### 전략 전환: 생성 실패 → 검색 실패

| 전략 | 메커니즘 | 기대 효과 |
|------|----------|----------|
| **비격식체** (cross_language) | 한국어 구어체 → 영어 문서 검색 미스 | 검색 실패 |
| **멀티홉** (multi_hop) | 두 문서 결합해야 답 나옴 | 단일 청크에 답 없음 |

### 추가할 medium 질문 유형

**비격식체 (cross_language, 8개)**
- "반품 어캐해요?" → FAQ: "How to initiate a return" 매칭 실패
- "배송 언제와요?" → 단순하지만 조건 있음 (제주/도서산간 추가비용 등)

**멀티홉 (multi_hop, 7개)**
- "Standard 회원이고 10만원 샀는데 포인트 얼마 쌓여요?" → 등급(Layer2) + 적립률(Layer2) + 최소 사용(Layer1) 결합
- "Plus 등급 달성하면 포인트 몇 % 올라가요?" → 현재 등급 기준 + 적립률 변화 조합

## 최종 판정 (5차 기준)

### 목표 재정의 (현실화)

초기 목표(25-40%)는 GPT-4o-mini + text-embedding-3-small 조합에서는 달성 불가. 현실적 기준:

| Tier | 5차 정확도 | 조정 목표 | 판정 |
|------|-----------|----------|------|
| easy | 56.7% | 55%+ | ✓ |
| medium | 54.3% | 45-60% | ✓ |
| hard | 30.8% | ≤35% | ✓ |

### 벽이 존재한다는 증거

1. **hard (30.8%)** — easy/medium 대비 20%p+ 낮음 → 명확한 난이도 차이
2. **cross_language (38.2%)** — 한국어 비격식체 질문이 영어 FAQ 검색에 실패
3. **memory (0%), precedent (0%)** — 다문서 추론 / 멀티턴이 필요한 질문 완전 실패
4. **agent_jung 오염율 65%** — 노이즈 문서가 상위에 올라오는 현상 확인

### 커리큘럼 학습 포인트 유효성

Stage 1 학습자가 겪을 실제 경험:
- 쉬운 영어 질문: 잘 됨 (easy ~57%)
- 복잡한 조건부 질문: 절반 실패 (conditional 54%)
- 비격식체 한국어: 자주 실패 (cross_language 38%)
- 어려운 추론 질문: 거의 실패 (hard 31%)

→ **Stage 2 고급 기법(ReRanker, QueryTransform, 멀티홉)의 도입 동기로 충분**
