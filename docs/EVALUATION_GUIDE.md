# 평가 가이드

모든 Stage 2 모듈은 동일한 평가 구조를 따릅니다.

## 평가 구조

### 1. 테스트 통과

```bash
./gradlew :stage2:mN:test
```

모든 테스트가 통과하면 기능 요구사항을 충족한 것입니다.
테스트는 최소 기준입니다 - 통과 자체가 좋은 구현을 보장하지는 않습니다.

### 2. 전후 비교 기록

모든 모듈은 "무엇이 바뀌었는지"를 수치로 기록해야 합니다.
모듈의 `EVALUATION.md`에 아래 형식으로 작성하세요.

```markdown
## Baseline (적용 전)

| 지표 | 값 | 측정 방법 |
|------|-----|----------|
|      |     |          |

## After (적용 후)

| 지표 | 값 | 측정 방법 |
|------|-----|----------|
|      |     |          |

## 변화

| 지표 | 변화량 | 해석 |
|------|--------|------|
|      |        |      |
```

### 3. 모듈별 핵심 지표

| 모듈 | 핵심 지표 | 측정 방법 |
|------|----------|----------|
| **M1** 벡터 DB | 적재 문서 수, 검색 속도, 재시작 후 데이터 유지 | PersistenceTest, 쿼리 응답 시간 |
| **M2** 검색 품질 | Top-1 정확도, Top-5 정확도 | 테스트 질문 100개 평가 |
| **M3** 관측성 | 장애 분류 정확도, 환각 탐지율, 비용 추적 | 의도적 실패 케이스 + 평가 파이프라인 |
| **M4** Tool Use | Tool 라우팅 정확도 (RAG vs Tool 선택) | 시나리오 5종 테스트 |
| **M5** 비용 최적화 | 요청당 비용, 캐시 히트율, 품질 유지 여부 | 동일 질문셋으로 비용 전후 비교 |
| **M6** 멀티 에이전트 | Medium tier 정확도 | 테스트 질문 중 medium 난이도 비교 |
| **M7** 인프라 | 실행까지 단계 수, 재현 성공률 | 다른 환경에서 docker compose up 테스트 |
| **M8** 대화 기억 | N턴 맥락 유지율, 토큰 예산 준수 | 3턴 이상 시나리오 테스트 |
| **M9** 스트리밍 | 첫 토큰 도달 시간(TTFT), 중단 시 비용 차단 | SSE 연결 + 중간 끊기 테스트 |
| **M10** 구조화 출력 | 스키마 준수율, 재시도 횟수 | 100회 호출 중 파싱 성공률 |
| **M11** 피드백 루프 | 자동 생성 FAQ 품질, 반영 후 정확도 변화 | 생성 FAQ 검증 + 정확도 재측정 |

### 4. 운영 품질 체크리스트

테스트 통과 + 수치 기록 외에, 아래 항목을 모든 모듈에서 확인하세요.

**보안**
- [ ] API 키가 환경변수로 관리됨 (코드에 하드코딩 없음)
- [ ] Actuator 엔드포인트가 외부에 노출되지 않음
- [ ] 입력값 검증 (빈 질문, 과도하게 긴 질문)

**안정성**
- [ ] 외부 서비스(OpenAI, Qdrant) 오류 시 적절한 에러 메시지 반환
- [ ] 타임아웃 설정 (LLM 호출 최대 30초)

**코드 품질**
- [ ] TODO 마커가 모두 구현으로 교체됨
- [ ] 테스트가 외부 서비스 없이도 설명 가능한 구조 (통합 테스트는 예외)

## EVALUATION.md 작성 예시

```markdown
# M2 검색 품질 - 평가 결과

## Baseline (M1 완료 직후)

| 지표 | 값 | 측정 방법 |
|------|-----|----------|
| Top-1 정확도 | 42% | test_questions.json 100개 |
| Top-5 정확도 | 71% | test_questions.json 100개 |
| 평균 응답 시간 | 1.2s | 100회 평균 |

## After (ReRanker + 쿼리 변환 적용)

| 지표 | 값 | 측정 방법 |
|------|-----|----------|
| Top-1 정확도 | 63% | test_questions.json 100개 |
| Top-5 정확도 | 85% | test_questions.json 100개 |
| 평균 응답 시간 | 2.1s | 100회 평균 |

## 변화

| 지표 | 변화량 | 해석 |
|------|--------|------|
| Top-1 정확도 | +21%p | ReRanker가 가장 큰 기여. 목표(+15%p) 달성 |
| Top-5 정확도 | +14%p | 쿼리 변환이 recall 개선에 기여 |
| 평균 응답 시간 | +0.9s | ReRanker 추가 호출로 인한 지연. 수용 가능 범위 |
```
