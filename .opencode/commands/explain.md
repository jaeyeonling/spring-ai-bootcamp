설명 대상: $ARGUMENTS

인자가 없으면 현재 프로젝트의 전체 구조와 아키텍처를 설명합니다.

## 사용 예시

- `/explain` - 프로젝트 전체 구조 설명
- `/explain embedding` - 임베딩 개념 설명
- `/explain rag` - RAG 파이프라인 개념 설명
- `/explain cosine` - 코사인 유사도 설명
- `/explain chunking` - 청킹 전략 설명
- `/explain vectorstore` - 벡터 저장소 개념 설명
- `/explain chatclient` - ChatClient API 설명
- `/explain prompt-engineering` - 프롬프트 엔지니어링 설명
- `/explain function-calling` - Function Calling 개념 설명
- `/explain mcp` - MCP 프로토콜 설명
- `/explain week01/src/main/.../ChatService.java` - 특정 파일 설명

Spring AI 개념은 백엔드 개발자에게 익숙한 비유와 다이어그램으로 쉽게 설명합니다.
