# Week 04 미션: "답변이 Top-5에는 있지만 Top-1에 없습니다"

## 상황

이전 주차에서 만든 RAG 챗봇이 운영 중입니다. 사용자들이 잘못된 답변을 신고합니다.

조사해보니 흥미로운 것을 발견합니다:

> **올바른** 문서 청크는 거의 항상 벡터 저장소의 상위 5개 결과에 있습니다.
> 하지만 **1위**가 아닙니다 — LLM은 1위 또는 2위만 봅니다.

평가 수치가 이야기를 말해줍니다:

| 지표            | 현재 값 |
|-------------------|---------------|
| Top-1 정확도    | 40%           |
| Top-5 정확도    | 80%           |
| 답변 정확도    | 35%          |

검색이 올바른 답변을 **찾기는** 합니다. 단지 먼저 **순위를 매기지** 못합니다.

매니저가 말합니다:

> "사용자들은 상위 5개에는 관심 없습니다. 답변에 관심이 있습니다. 순위를 수정하세요."

## 요구사항

### 목표

검색 개선 기법을 사용해 **Top-1 정확도**를 40%에서 **60% 이상**으로 향상시키세요.

### 기법

다음 기법 중 **최소 2가지**를 적용해야 합니다:

1. **ReRanker** — 더 큰 후보 집합(예: 상위 20개)을 검색한 후, LLM 또는 크로스 인코더를 사용해 관련성에 따라 재점수화하고 재정렬합니다.
2. **쿼리 변환** — 벡터 저장소에 보내기 전에 사용자 쿼리를 재작성, 압축 또는 확장합니다.
3. **하이브리드 검색** — 벡터 유사도와 키워드 기반 검색(BM25)을 결합합니다.

### 아키텍처

검색 전략을 교체 가능하게 만들기 위해 **Strategy 패턴** 사용:

```java
public interface RetrievalStrategy {
    List<Document> retrieve(String query, int topK);
}
```

최소 3가지 구현이 있어야 합니다:
- `BaselineRetrieval` — 일반 벡터 검색 (현재 방식)
- `ReRankingRetrieval` — 상위 N개 검색, LLM으로 재순위화
- `QueryTransformRetrieval` — 검색 전 쿼리 변환

Spring 설정 또는 프로파일을 통해 전략을 전환할 수 있어야 합니다.
