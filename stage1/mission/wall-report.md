## Stage 2 모듈 선택 가이드

벽 리포트를 작성한 후, 아래 표에서 자신이 겪은 증상과 가장 가까운 모듈을 선택하세요.
독립 모듈은 순서 없이 자유 선택 가능합니다. 선수 조건이 있는 모듈은 해당 모듈을 먼저 완료해야 합니다.

### 독립 모듈 (Stage 1만 완료하면 바로 시작 가능)

| 겪은 증상 | 모듈 | 배우는 것 |
|----------|------|----------|
| 서버 재시작하면 임베딩 날아감, 검색이 느림 | **M1** 벡터 DB & ETL | Qdrant, ETL 파이프라인, 메타데이터 필터링 |
| 문서에 없는 실시간 정보(주문 상태 등)를 못 답함 | **M4** Tool Use & MCP | @Tool, 함수 호출, MCP 프로토콜 |
| API 비용이 너무 나옴, 단순 질문에도 GPT 호출 | **M5** 비용 최적화 | 시맨틱 캐싱, Ollama, 모델 라우팅 |
| 로컬에서만 됨, 다른 사람이 실행 못함 | **M7** 인프라 | Docker Compose, 프로파일 분리 |
| 이전 대화 맥락을 기억 못함 | **M8** 대화 기억 | ChatMemory, 슬라이딩 윈도우 |
| 답변 완성까지 기다려야 함, 취소 불가 | **M9** 스트리밍 & 응답 제어 | SSE, 클라이언트 인터럽트 |
| LLM 응답 형식이 매번 달라서 파싱 불가 | **M10** 구조화 출력 | entity(), 스키마 강제, 자동 재시도 |

### 선수 조건이 있는 모듈

| 겪은 증상 | 모듈 | 선수 조건 | 배우는 것 |
|----------|------|----------|----------|
| 답이 Top-5엔 있는데 Top-1이 아님 | **M2** 검색 품질 | M1 | ReRanker, 쿼리 변환, 하이브리드 검색 |
| 버그인지 모델 문제인지 구분 불가, 메트릭 없음 | **M3** 관측성 & 평가 | M1 | Micrometer, OTel, 환각 탐지 |
| 여러 데이터 소스를 조합해야 하는 질문에 못 답함 | **M6** 멀티 에이전트 | M4 | Chain / Routing / Orchestrator 패턴 |
| 좋은 답변이 지식에 반영 안 됨, 같은 질문 반복 | **M11** 데이터 피드백 루프 | M1 + M3 | 패턴 감지, FAQ 자동 생성 |

### 선택 팁

- 벽 리포트 1~2번에서 가장 답답했던 문제부터 해결하세요.
- 한 번에 여러 모듈을 선택하지 않아도 됩니다. 하나를 끝내고 다음을 고르세요.
- 정확도가 낮았다면 M1 → M2 순서를 추천합니다.
- 정확도보다 사용성이 문제였다면 M8, M9, M10 중에서 선택하세요.
