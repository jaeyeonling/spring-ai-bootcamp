# Week 01 미션: "FAQ 챗봇 만들기"

## 상황

초록 코퍼레이션에 백엔드 개발자로 입사했습니다.
고객지원팀은 매일 같은 질문을 수백 번 답하느라 지쳐 있습니다.

매니저가 다가와 말합니다:

> "FAQ 문서가 있어요. 사용자가 질문을 보내면 답을 돌려주는 REST API를 만들어주세요.
> AI 기술을 사용하면 돼요. 금요일까지요."

그게 전부입니다. 추가 안내는 없습니다. 알아서 해결하세요.

## 요구사항

### API 명세

```
POST /api/chat

요청:
{
  "question": "환불은 어떻게 받나요?"
}

응답:
{
  "answer": "환불을 요청하려면 내 주문으로 이동하여 해당 주문을 선택하세요...",
  "tokenUsage": {
    "promptTokens": 542,
    "completionTokens": 87,
    "totalTokens": 629
  }
}
```

### 제약사항

- FAQ 문서는 `../data/faq.md`에 있습니다 (약 3페이지 분량)
- **참고**: FAQ 문서(`../data/faq.md`)와 테스트 질문(`../data/test_questions.json`)은
  영어로 작성되어 있습니다. 그러나 실제 서비스에서는 한국어 질문이 들어올 수 있으므로,
  테스트 코드에서는 한국어 질문을 사용합니다.
  최신 임베딩 모델(text-embedding-3-small 등)은 다국어를 지원하므로
  cross-language 검색이 가능합니다. 한국어 질문과 영어 FAQ 간의 의미적 매칭이
  잘 되는지 확인하세요.
- Spring AI의 `ChatClient`를 통해 OpenAI API를 **반드시** 사용해야 합니다
- RAG 프레임워크, 벡터 저장소, `VectorStore` 인터페이스는 **사용하지 마세요**
- 토큰 사용량을 응답에 포함하거나 로그에 기록해야 합니다
- 실행 방법을 README에 포함하세요

### 완료 기준

`src/test/` 디렉터리의 테스트가 인수 기준을 정의합니다:
- `POST /api/chat`이 200 응답과 함께 답변을 반환한다
- 답변이 질문과 관련 있다 ("모르겠습니다" 같은 일반적인 답변이 아님)
- 응답에 토큰 사용량이 포함되어 있다
- 어떤 방식으로든 FAQ 문서를 활용한다 (방법은 자유)
