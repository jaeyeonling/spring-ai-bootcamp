# 힌트 02: 프롬프트 엔지니어링 — 퓨샷과 사고의 사슬

## 프롬프트가 중요한 이유

1주차 프롬프트는 아마 이런 형태였을 것입니다:

```
당신은 초록 코퍼레이션의 고객지원 담당자입니다.
아래의 컨텍스트에 기반해서만 질문에 답하세요.
컨텍스트에 답이 없으면 "해당 정보를 찾을 수 없습니다."라고 말하세요.

컨텍스트:
{context}
```

작동하긴 하지만 LLM은 **좋은 답변이 어떤 것인지** 모릅니다. 그래서:
- 사용자가 세부 정보를 원하는데 한 단어로 답할 수 있습니다
- 한 문장으로 충분할 때 단락을 쓸 수 있습니다
- 컨텍스트의 구체적인 숫자(가격, 일수 등)를 놓칠 수 있습니다

## 기법 1: 퓨샷 프롬프팅

시스템 프롬프트에 2-3개의 이상적인 Q&A 예시를 제공합니다.
이를 통해 LLM이 기대하는 형식과 세부 수준을 학습합니다.

```java
String systemPrompt = """
    당신은 초록 코퍼레이션의 고객지원 담당자입니다.
    아래의 컨텍스트에 기반해서만 질문에 답하세요.
    컨텍스트에 답이 없으면 "해당 정보를 찾을 수 없습니다."라고 말하세요.

    좋은 답변의 예시:

    질문: 표준 배송은 얼마나 걸리나요?
    답변: 표준 배송은 영업일 기준 3-5일이 소요됩니다. 더 빠른 배송을 원하시면
    익스프레스 배송을 이용하시면 익일 배송이 3,000원에 가능합니다.

    질문: 제품을 반품할 수 있나요?
    답변: 네, 배송 후 30일 이내에 어떤 제품이든 반품할 수 있습니다.
    결함이나 당사의 실수로 인한 반품이 아닌 경우, 반품 배송비로 2,500원이
    환불 금액에서 공제됩니다.

    질문: 어떤 결제 방법을 지원하나요?
    답변: 신용카드(Visa, Mastercard, BC카드), 카카오페이,
    네이버페이, 토스를 지원합니다. 50,000원 이상 주문 시
    무이자 할부도 가능합니다.

    이제 아래 컨텍스트를 사용해 다음 질문에 답하세요.
    구체적으로 — 숫자, 가격, 기간이 있으면 포함하세요.

    컨텍스트:
    %s
    """.formatted(context);
```

### 이것이 효과적인 이유

LLM이 예시에서 배웁니다:
- 답변은 1-3문장이어야 함
- 구체적인 숫자를 포함해야 함 (3-5일, 2,500원)
- 관련 정보를 언급해야 함 (익스프레스 옵션, 결함 예외)

## 기법 2: 사고의 사슬 (CoT)

LLM이 **답변 전에 추론**하도록 요청합니다. 이렇게 하면 답변을 생성하기 전에
컨텍스트의 관련 부분을 식별하도록 강제합니다.

```java
String systemPrompt = """
    당신은 초록 코퍼레이션의 고객지원 담당자입니다.
    아래의 컨텍스트에 기반해서만 질문에 답하세요.

    다음 단계를 따르세요:
    1. 질문과 가장 관련 있는 컨텍스트 섹션을 파악하세요
    2. 해당 섹션에서 구체적인 사실(숫자, 날짜, 가격)을 추출하세요
    3. 그 사실을 사용해 명확하고 간결한 답변을 작성하세요

    컨텍스트에 답이 없으면 "해당 정보를 찾을 수 없습니다."라고 말하세요.

    컨텍스트:
    %s
    """.formatted(context);
```

### 두 기법 결합

퓨샷과 CoT를 함께 사용할 수 있습니다:

```java
String systemPrompt = """
    당신은 초록 코퍼레이션의 고객지원 담당자입니다.
    아래의 컨텍스트에 기반해서만 질문에 답하세요.

    단계별로 생각하세요:
    1. 컨텍스트에서 관련 섹션 찾기
    2. 구체적인 사실(숫자, 가격, 기간) 추출
    3. 명확한 답변 작성

    좋은 답변 예시:

    Q: 배송은 얼마나 걸리나요?
    A: 표준 배송은 영업일 기준 3-5일입니다. 익스프레스 배송은
    3,000원에 익일 배송이 가능합니다.

    Q: 반품 기간이 어떻게 되나요?
    A: 배송 후 30일 이내에 어떤 제품이든 반품할 수 있습니다.

    컨텍스트:
    %s
    """.formatted(context);
```

## Spring AI ChatClient 사용법

Spring AI의 `ChatClient`와 연결하는 방법:

```java
ChatResponse response = chatClient.prompt()
    .system(systemPrompt)
    .user(question)
    .call()
    .chatResponse();

String answer = response.getResult().getOutput().getText();
```

### 더 깔끔한 코드를 위한 PromptTemplate

String.format 대신 Spring AI의 `PromptTemplate` 사용:

```java
import org.springframework.ai.chat.prompt.PromptTemplate;

PromptTemplate template = new PromptTemplate("""
    당신은 초록 코퍼레이션의 고객지원 담당자입니다.
    이 컨텍스트에만 기반하여 답하세요:

    {context}
    """);

String systemPrompt = template.render(Map.of("context", context));
```

## 시도해볼 것

1. 1주차 프롬프트를 기준선으로 시작
2. 퓨샷 예시 추가 → 평가 실행 → 측정
3. CoT 지침 추가 → 평가 실행 → 측정
4. 둘 다 결합 → 평가 실행 → 측정

핵심 통찰: **프롬프트 엔지니어링은 경험적입니다**. 측정하기 전에는 무엇이 효과적인지
알 수 없습니다. 그래서 자동화된 평가(힌트 03)가 중요합니다.
