## 아키텍처 다이어그램

```mermaid
graph TB
    subgraph Clients
        WEB[웹 브라우저]
        IDE[IDE / Claude Desktop]
        API[API 클라이언트]
    end

    subgraph Application["Spring Boot 애플리케이션"]
        REST[REST 컨트롤러]
        MCP[MCP 서버]
        CHAT[챗봇 서비스]
        RAG[RAG 파이프라인]
        TOOLS[툴 서비스]
        EVAL[평가 파이프라인]
        OTEL[OpenTelemetry]
    end

    subgraph Infrastructure
        QDRANT[Qdrant 벡터 DB]
        JAEGER[Jaeger 트레이싱]
        LLM[OpenAI API]
    end

    WEB --> REST
    IDE --> MCP
    API --> REST

    REST --> CHAT
    MCP --> CHAT
    MCP --> TOOLS

    CHAT --> RAG
    CHAT --> TOOLS
    CHAT --> LLM

    RAG --> QDRANT
    RAG --> LLM

    OTEL --> JAEGER
    CHAT -.-> OTEL
    RAG -.-> OTEL
    TOOLS -.-> OTEL
```
