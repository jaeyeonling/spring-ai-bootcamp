# Week 10 미션: "배포하세요 — 최종 프로젝트"

## 상황

9주 동안 AI 엔지니어링 스킬을 하나씩 쌓아왔습니다:

| 주차 | 만든 것 | 핵심 개념 |
|------|---------------|-------------|
| 01 | Raw LLM 호출로 FAQ 챗봇 | 프롬프트 엔지니어링, ChatClient |
| 02 | 평가 파이프라인 + 청킹 전략 | 벡터 유사도, 청킹, RelevancyEvaluator |
| 03 | 벡터 데이터베이스 통합 | Qdrant, 영속성, ETL 파이프라인 |
| 04 | 고급 검색 전략 | ReRanking, 쿼리 변환, 하이브리드 검색 |
| 05 | 관찰 가능성 및 트레이싱 | OpenTelemetry, Micrometer, 토큰 추적 |
| 06 | 로컬 모델 배포 | Ollama, 비용 분석, Kubernetes |
| 07 | 툴 호출 및 함수 통합 | @Tool, 외부 API 통합 |
| 08 | 멀티 에이전트 워크플로우 | Chain, Routing, Orchestrator-Worker |
| 09 | MCP 서버 | 프로토콜 표준화, IDE 통합 |

이제 모두 합칠 시간입니다.

최종 프로젝트: **1주차 FAQ 챗봇을 운영 수준의 AI 서비스로 재구축하기**
지금까지 배운 모든 것을 통합하여.

## 요구사항

### 체크리스트

최종 프로젝트에는 다음 **모든 항목**이 포함되어야 합니다:

- [ ] **고급 검색이 포함된 하이브리드 RAG** — 벡터 검색 + 키워드 검색 + 재순위화
      (2-4주차)
- [ ] **자동화된 평가 파이프라인** — RAGAS 스타일 메트릭, 모든 변경에 실행
      (5주차)
- [ ] **OpenTelemetry 트레이싱** — 모든 LLM 호출, 검색, 툴 호출에 트레이스
      (5주차)
- [ ] **Docker Compose 배포** — 전체 스택을 시작하는 하나의 명령어
- [ ] **툴 호출** — 최소 2개 툴 (예: 주문 조회, 에스컬레이션)
      (7주차)
- [ ] **MCP 서버** — IDE 통합을 위해 주요 기능을 MCP로 노출
      (9주차)
- [ ] **아키텍처 다이어그램** — 모든 컴포넌트를 보여주는 Mermaid 다이어그램
- [ ] **API 문서** — 엔드포인트, 요청/응답 형식
- [ ] **비용 분석** — 다양한 사용량 수준에서의 쿼리당 예상 비용
- [ ] **Week 1 vs Week 10 비교** — 두 버전을 통해 같은 30개 테스트 질문 실행

### 발표

간단한 발표 (5-10분) 준비:

1. **아키텍처 개요** — 어떤 컴포넌트들이 있고 어떻게 연결되는지
2. **비교** — Week 01 vs Week 10 수치
3. **핵심 결정사항** — 어떤 트레이드오프를 했고 왜
4. **다르게 했을 것** — 돌이켜보면 무엇을 바꿨을지
5. **운영 준비도** — 실제 운영 배포에서 무엇이 부족한지

### 완료 기준

- `docker compose up`으로 전체 스택 시작 (앱 + Qdrant + 선택적 Ollama + 선택적 Jaeger)
- 챗봇이 높은 정확도로 FAQ 질문에 답한다
- 최소 2개 툴이 LLM에 의해 호출 가능하다
- MCP 서버가 MCP 클라이언트에서 접근 가능하다
- Jaeger (또는 콘솔)에서 트레이스가 보인다
- 평가 파이프라인이 실행되고 메트릭을 생성한다
- 아키텍처 문서가 Mermaid 다이어그램과 함께 완성된다
- Week 01 vs Week 10 비교 표가 채워진다

## 시작하는 방법

1. `docker-compose.yml`부터 시작 — 인프라를 실행하세요
2. 이전 주차에서 최선의 코드를 `week10` 프로젝트에 복사
3. `Week10Application.java`에서 모든 것 연결
4. Week 01과 Week 10 모두에 대해 평가 파이프라인 실행
5. `ARCHITECTURE.md` 작성
6. 발표 준비

### API 명세

최종 챗봇의 `/api/chat` 엔드포인트는 다음 형식의 응답을 반환해야 합니다:

```json
{
  "answer": "30일 이내에 반품이 가능합니다...",
  "sources": ["faq-chunk-1", "faq-chunk-2"],
  "tokenUsage": {
    "promptTokens": 150,
    "completionTokens": 80,
    "totalTokens": 230
  }
}
```

Week 01의 `ChatController`와 Week 03의 `QueryController`를 참고해
`answer`, `sources`, `tokenUsage`를 모두 포함하는 통합 응답을 설계하세요.
