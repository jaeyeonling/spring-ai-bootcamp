# 힌트 03: 비용 분석 프레임워크

## 목표

CTO는 의견이 아닌 숫자가 담긴 스프레드시트를 원합니다.
방어 가능한 비용 비교를 만들기 위한 프레임워크를 소개합니다.

## 1단계: 현재 사용량 측정

비교하기 전에 실제 사용량을 알아야 합니다:

```
현재 월간 통계:
- 총 API 호출:          ~50,000 /월
- 평균 입력 토큰/호출:    ~800 토큰
- 평균 출력 토큰/호출:   ~200 토큰
- 총 입력 토큰:          40,000,000 /월
- 총 출력 토큰:          10,000,000 /월
- 모델:                  gpt-4o-mini
```

OpenAI 사용량 대시보드나 토큰 수 로깅을 통해 얻을 수 있습니다.

## 2단계: API 비용 계산

```
OpenAI gpt-4o-mini 가격 (2024 기준):
- 입력:  $0.150 / 1M 토큰
- 출력: $0.600 / 1M 토큰

월 비용:
- 입력:  40M * $0.150/1M = $6.00
- 출력: 10M * $0.600/1M = $6.00
- 합계: $12.00  (잠깐, $2,000보다 훨씬 적네요?)
```

실제 청구가 $2,000이라면, gpt-4o-mini가 아닌 gpt-4o를 사용하고 있을 가능성이 큽니다:

```
OpenAI gpt-4o 가격:
- 입력:  $2.50 / 1M 토큰
- 출력: $10.00 / 1M 토큰

월 비용:
- 입력:  40M * $2.50/1M  = $100
- 출력: 10M * $10.00/1M = $100
- 합계: $200

흠, 여전히 $2,000이 아닙니다. 볼륨이나 모델을 다시 확인하세요.
```

요점: **먼저 측정하고, 그 다음에 계산하세요.** 추측하지 마세요.

## 5단계: 손익분기점 계산

```
손익분기점 = 자체 호스팅 월 비용 / 요청당 API 비용

예시:
- 자체 호스팅 A10G 비용: $725/월
- OpenAI gpt-4o 요청당 비용: ($2.50 * 0.8 + $10.00 * 0.2) / 1000 = $0.004/요청
- 손익분기점: $725 / $0.004 = 181,250 요청/월

월 ~18만 건 이상의 요청을 하면 자체 호스팅이 더 저렴합니다.
```

다음 사항도 고려하세요:
- 설정 및 유지보수를 위한 엔지니어링 시간 (시급 기준)
- 기회 비용 (그 시간에 다른 무엇을 만들 수 있었나?)
- 다운타임 위험 (이제 본인이 운영팀)
